# Comfortaa

Original variable font from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/comfortaa

Downloaded font:
https://raw.githubusercontent.com/google/fonts/main/ofl/comfortaa/Comfortaa%5Bwght%5D.ttf

The unmodified font and its SIL Open Font License are retained together here.
`scripts/font_outlines.py` turns letterforms into SVG paths at build time so
GitHub visitors do not need Comfortaa installed or an external font request.
Ordinary Markdown text uses GitHub's own typography.
